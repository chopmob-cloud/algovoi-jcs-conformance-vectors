# compliance_gate_keystone_v1 (compliance verdict binds the keystone decision)

Composition proof that the compliance gate verdict is bound into the keystone decision:

```
compliance gate (ALLOW/REFER/DENY)            keystone decision
  gate_ref = SHA-256(JCS({payer_ref,            decision_ref = SHA-256(JCS({agent_ref,
    subject_ref, verdict}))                       mandate_ref, policy_bound_ref, verdict}))
            └─ subject_ref ── IS ── policy_bound_ref ──┘
  trust_query_ref over [passport, mandate, policy, gate, decision, execution]   (compliance-spanning cap)
```

The keystone proves identity + authority + policy compose into a decision. This proves the other
half of admissibility: the compliance gate assessed the **exact `policy_bound_ref` the decision
used**, so the decision was admitted under the compliance verdict in force. A compliance-spanning
`trust_query_ref` then caps the chain including the gate.

Reuses `compliance_gate_lite_v1` (`gate_ref`, the published `cg-allow-P` golden over the keystone
policy), the keystone `decision_ref`, and `trust_query_ref`. No new hashing primitive.

Run:
```
python verify_compliance_gate_keystone.py    # pip install rfc8785
node   verify_compliance_gate_keystone.mjs   # npm install canonicalize
```
PASS 5/5, Python and Node byte for byte. `compliance_gate_keystone_trace.json` is regenerated by
`generate_compliance_gate_keystone.py`.
