# cancellation_keystone_v1 (cancellation closes the keystone authority)

Composition proof that a cancellation receipt closes the exact authority the keystone used, the
authority-side mirror of `refund_execution_v1`:

```
cancellation_ref = "sha256:" + SHA-256(JCS({cancellation_reason, mandate_ref}))
                                                              └── IS the keystone mandate_ref
```

Cancellation closes the **authority before execution**; refund closes the **payment after
execution**. Together they bracket the keystone: `cancellation_keystone_v1` binds `mandate_ref`,
`refund_execution_v1` binds `execution_ref`. The closed-enum reason (USER_REQUESTED /
MERCHANT_REQUESTED / COMPLIANCE_TERMINATED / EXPIRED) is byte-load-bearing.

Reuses `cancellation_receipt_lite_v1` (the published `cn-001` golden over the keystone mandate) and
the keystone `mandate_ref`. No new hashing primitive.

Run:
```
python verify_cancellation_keystone.py    # pip install rfc8785
node   verify_cancellation_keystone.mjs   # npm install canonicalize
```
PASS 4/4, Python and Node byte for byte. `cancellation_keystone_trace.json` is regenerated by
`generate_cancellation_keystone.py`.
